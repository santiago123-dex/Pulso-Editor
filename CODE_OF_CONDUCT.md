# Código de conducta

Queremos que participar en Pulso Editor sea una experiencia respetuosa para todas las personas, sin importar su experiencia, idioma, origen o forma de ser.

## Lo que esperamos

- Tratar a los demás con respeto y buena fe, también cuando no se esté de acuerdo.
- Criticar el código y las ideas, no a las personas.
- Aceptar con calma las críticas útiles y ayudar a quien empieza.

## Lo que no se acepta

- Insultos, acoso, discriminación o amenazas.
- Publicar información privada de otras personas sin su permiso.
- Spam o publicidad que no tenga que ver con el proyecto.

## Qué pasa si se incumple

Quien mantiene el proyecto puede editar o borrar comentarios, issues y PR que incumplan este código, y bloquear a quien lo haga de forma repetida.

Para reportar un problema de conducta, escribe en privado a quien mantiene el proyecto desde su perfil de GitHub ([santiago123-dex](https://github.com/santiago123-dex)). Se tratará con discreción.
